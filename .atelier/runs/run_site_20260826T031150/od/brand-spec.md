# Newton Tool Repair — Brand Specification

Newton Tool Repair uses an industrial-precision system: deep graphite ground, machined-steel surfaces, optical-white type, and one restrained safety-amber signal.

## Typography

- Display: "Space Grotesk", "Arial Narrow", sans-serif
- Body: "Plus Jakarta Sans", Arial, sans-serif
- Mono: "JetBrains Mono", "SFMono-Regular", Consolas, monospace

## Visual Language

- Use graphite as the working floor and raised tool-steel panels as precise, square-edged zones.
- Let grids, hairline strokes, serial tags, and measurement marks carry the industrial character; avoid decorative glow.
- Use amber as paint: for one decisive action or a calibrated marker, never as a wash.
- Keep type large, direct, and contractor-oriented; technical labels use the mono face with generous uppercase tracking.
- Favor useful workshop detail—status, model numbers, service path, and bench notes—over generic marketing ornament.
